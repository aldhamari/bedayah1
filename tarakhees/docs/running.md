# تشغيل النظام على جهازك

دليل التشغيل المحلي، من مستودع نظيف إلى شاشة تعمل.

---

## ما تحتاجه أولًا

| | الإصدار | للتحقق |
|---|---|---|
| Node.js | ٢٠ فأعلى | `node -v` |
| npm | ١٠ فأعلى | `npm -v` |
| Docker | أي إصدار حديث فيه `docker compose` | `docker compose version` |

Docker يشغّل PostgreSQL 16 و Redis 7 فقط. إن كان لديك الاثنان مثبّتين
محليًا فلا تحتاجه — عدّل `DATABASE_URL` و`REDIS_HOST` في `.env` وتخطَّ
خطوة `db:up`.

> **على ويندوز ولم تثبّت شيئًا بعد؟** ابدأ من
> [`docs/install-windows.md`](./install-windows.md) — دليل من الصفر
> يشمل أعطال ويندوز الشائعة.

---

## التشغيل — أربعة أوامر

```bash
cd tarakhees

npm install        # يبني الحزمة المشتركة ويولّد عميل Prisma تلقائيًا
npm run setup      # ينشئ .env بأسرار مولَّدة، يرفع Postgres و Redis،
                   # يطبّق الترحيلين، ويزرع ٢٧ نوع ترخيص سعودي
```

ثم في **طرفيتين منفصلتين**:

```bash
npm run dev:api    # http://localhost:4000/api
npm run dev:web    # http://localhost:3000
```

افتح <http://localhost:3000> — ستُحوَّل إلى صفحة الدخول.

## أول خمس دقائق

1. **`/register`** — سجّل منشأتك. أول تسجيل يُنشئ المستخدم والمنشأة
   ويجعلك `OWNER`، ويضبط مهل التنبيه الافتراضية (٦٠ · ٣٠ · ٧ · يوم
   الانتهاء) على قناتَي البريد وداخل النظام.

2. يأخذك النظام مباشرة إلى **الإدخال السريع**، وسيطلب منك فرعًا أولًا —
   كل ترخيص منشأة يرتبط بفرع.

3. **`/facilities`** — أضف «الفرع الرئيسي».

4. ارجع إلى **الإدخال السريع** والصق هذا مباشرة في مربع اللصق
   (الأعمدة مفصولة بـ Tab، وهو ما تُخرجه إكسل عند النسخ):

   ```
   رخصة بلدية	الفرع الرئيسي	ML-1001	2026-10-15
   سجل تجاري	الفرع الرئيسي	CR-2002	15/11/2026
   شهادة السلامة	الفرع الرئيسي	CD-3003	١٥-٠٥-١٤٤٨
   ```

   لاحظ ثلاث صيغ تاريخ مختلفة — النظام يقرؤها كلها، ويخمّن النوع من
   النص العربي الحر.

5. **`/`** — لوحة القيادة الآن ممتلئة: البطاقات الأربع، الشريط الزمني،
   وجدول «يحتاج انتباهك».

6. جرّب **جدّد** من أي صف، ثم افتح الترخيص وتبويب **سجل الفترات**:
   الفترة القديمة محفوظة بتاريخها وتكلفتها ومعلَّمة «أُغلقت».

## التحقق من أن كل شيء سليم

```bash
npm test           # ٥٩ اختبار jest (parsers + المجدول)
npm run verify     # ١٠٤ فحص عبر HTTP فعلي (العزل + مسارات الـAPI)
npm run build      # يبني shared ثم api ثم web
```

`npm run verify` يحتاج قاعدة البيانات و Redis يعملان.

## التنبيهات

المهمة الليلية تعمل **٧:٠٠ صباحًا بتوقيت الرياض**. لاختبارها بلا انتظار،
اضبط بريدك في `SUPER_ADMIN_EMAILS` داخل `.env`، أعد تشغيل الـAPI، ثم:

```bash
curl -X POST http://localhost:4000/api/admin/reminders/run \
  -H "Authorization: Bearer <رمز الوصول>"
```

يقبل `?date=YYYY-MM-DD` لمحاكاة يوم آخر — مفيد لرؤية سلوك المهل المختلفة.

> الإرسال الفعلي على واتساب والرسائل النصية يحتاج تهيئة مزوّد في `.env`،
> وقالبًا معتمدًا مسبقًا لدى Meta في حالة واتساب. بدونها تُسجَّل محاولة
> الإرسال في سجل الإشعارات بحالة `FAILED` — وهذا سلوك مقصود، لا عطل.

## تعثّرت؟ ابدأ من هنا

```bash
npm run doctor
```

يفحص كل نقطة تعثّر محتملة — إصدار Node، Docker، أسرار `.env` وأطوالها،
بناء الحزمة المشتركة، عميل Prisma، اتصال Postgres و Redis، الترحيلات،
البذور — ويطبع بجانب كل عطل **أمر إصلاحه**. لا يُعدّل شيئًا.

إن خرج نظيفًا وبقيت المشكلة، شغّل `npm run dev:api` وانسخ الخطأ كاملًا.

## أسئلة تتكرر

**`.env` — هل أعدّله بيدي؟**
لا حاجة. `npm run env:init` يولّد كل الأسرار بالطول الصحيح، ولا يمسّ
`.env` إن كان موجودًا.

**⚠️ `FIELD_ENCRYPTION_KEY` هو المفتاح الوحيد الذي يفكّ أرقام الهوية
المحفوظة.** احفظ نسخة منه في مكان منفصل عن قاعدة البيانات. فقدانه يعني
فقدانها كلها، ونسخة احتياطية من القاعدة وحدها لا تكفي لاستعادتها.

**المنفذ ٥٤٣٢ مشغول عندي.**
غيّر `POSTGRES_PORT` في `.env` وحدّث المنفذ داخل `DATABASE_URL` معه،
ثم `npm run db:up`.

**`npm run dev:api` يشتكي من `@repo/shared`.**
`npm install` يبنيها تلقائيًا. إن حدث بعد سحب تغييرات جديدة:
`npm run build --workspace=packages/shared`.

**كيف أبدأ من قاعدة نظيفة؟**
```bash
npm run db:down          # يوقف الحاويتين
docker volume rm tarakhees_postgres-data tarakhees_redis-data
npm run setup
```

**نسيت كلمة المرور.**
لا توجد شاشة استعادة بعد. احذف المستخدم من قاعدة البيانات وسجّل من
جديد، أو استخدم `npm run prisma:studio` لتعديله مباشرة.

## ما ليس مبنيًا بعد

- **إرسال الدعوات بالبريد** — رابط الدعوة يظهر في شاشة الإعدادات لتنسخه
  وترسله بنفسك.
- **رفع المرفقات** — جدول `Document` موجود في المخطط، وشاشة الترخيص
  تعرض عدد المرفقات، لكن الرفع نفسه غير مبنيّ.
- **طلبات التجديد عبر مزوّد خدمة** — النموذجان `ServiceProvider` و
  `RenewalRequest` في المخطط بلا واجهات.
- **استعادة كلمة المرور**.

وراجع قائمة «قبل أول عميل» في
[`docs/license-tracker-design.md`](./license-tracker-design.md) — فيها
المراجعة القانونية وبند المسؤولية في الاتفاقية والنسخ الاحتياطي
المُختبَر استعادته.
