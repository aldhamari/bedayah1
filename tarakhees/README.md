# نظام متابعة التراخيص — حزمة البدء

كل ما بُني حتى الآن، بمساراته الصحيحة، جاهز ليكمله Claude Code.

---

## الخطوات

### ١. فكّ الضغط وافتح المجلد في الطرفية

```bash
unzip tarakhees.zip
cd tarakhees
git init
```

### ٢. شغّل Claude Code في نفس المجلد

```bash
claude
```

### ٣. أعطه هذه الجملة حرفيًا

```
اقرأ CLAUDE.md كاملًا ثم docs/license-tracker-design.md.
نفّذ المهمة الأولى فقط (تجهيز الهيكل) واعرض النتيجة قبل أن تكمل.
```

سيقرأ `CLAUDE.md` تلقائيًا في كل جلسة بعدها، فلن تحتاج إعادة الشرح.

### ٤. اعمل مهمة واحدة في كل مرة

المهام مرقّمة من ١ إلى ٦ في `CLAUDE.md`. بعد كل واحدة:

```bash
git add -A && git commit -m "المهمة ٢: قاعدة البيانات"
```

الالتزام بعد كل مهمة يعني أن أي خطأ لاحق تتراجع عنه بأمر واحد بدل
أن تخسر يوم عمل.

---

## ما ستحتاج تجهيزه بالتوازي

هذه تستغرق أيامًا خارج يدك، فابدأها من الآن ولا تنتظر انتهاء البناء:

- **قالب واتساب معتمد** لدى Meta — اسم القالب `license_expiry_notice`
  وترتيب متغيراته `{{1}}` إلى `{{5}}` كما في `reminder.templates.ts`
- **مزوّد رسائل نصية** محلي وحساب فيه
- **حساب SMTP** للبريد
- **مراجعة قانونية** لسياسة الخصوصية — معالجة أرقام الهوية والإقامة
  تقع تحت نظام حماية البيانات الشخصية

## بينما يُبنى النظام

اتصل بعشرة أصحاب منشآت تعرفهم واسألهم سؤالًا واحدًا:

> كم غرامة تأخير تجديد دفعت في آخر سنتين؟

هذه المكالمات تحدد سعرك بدقة أكبر من أي تخمين، وتعطيك أول عملاء
قبل أن يكتمل المنتج. الأهم: إن لم يدفع أحد منهم غرامة، فالمشكلة
التي تبنيها غير موجودة — وهذا شيء تريد أن تعرفه اليوم لا بعد شهرين.
