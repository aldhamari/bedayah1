# نظام بداية لإدارة الأعمال

نظام متكامل لإدارة الأعمال (محاسبة، مبيعات، مشتريات، مخزون، نقطة بيع، موارد بشرية ورواتب) مُعدّ خصيصًا لـ **محامص وعطارة بداية**، بواجهة عربية كاملة (RTL)، متوافق مع متطلبات السوق السعودي (ريال سعودي، ضريبة قيمة مضافة 15%، توقيت آسيا/الرياض).

> **حالة المشروع الحالية:** تم إنجاز **المرحلة 1 (الأساس)**، **المرحلة 2 (نواة المحاسبة - الجزء الأساسي)**، **المرحلة 3 (المبيعات والمشتريات)**، **المرحلة 4 (المخزون - الجزء الأساسي)**، و**المرحلة 5 (نقطة البيع)** بشكل كامل وحقيقي وقابل للتشغيل والاختبار: عملاء وموردون، فواتير ضريبية مع ترحيل محاسبي تلقائي متوازن، مرتجعات، مقبوضات/مدفوعات، أعمار ذمم، منتجات وتصنيفات، تقييم مخزون بالمتوسط المرجّح، منع مخزون سالب، قيد تكلفة مبيعات آلي، وشاشة نقطة بيع لمسية كاملة (ورديات كاشير، مسح باركود بما فيه الموزون، دفعات مقسّمة، تعليق/استئناف بيع، إيصال حراري 80مم). كما بُنيت **المرحلة 6 (الفوترة الإلكترونية)** كـ**سقالة تقنية فقط - غير معتمدة من ZATCA** (رمز QR صحيح للمرحلة الأولى، سلسلة تجزئة فواتير، هيكل XML مرجعي غير موقَّع؛ راجع [docs/zatca.md](docs/zatca.md) للقيود الكاملة قبل أي استخدام رسمي)، **المرحلة 7 (الموارد البشرية والرواتب)** بشكل كامل وحقيقي وقابل للتشغيل والاختبار: هيكل تنظيمي وعقود عمل، حضور وانصراف، إجازات برصيد يُتحقَّق منه مرتين، ومحرك رواتب كامل مع نسب GOSI مؤرَّخة الفعالية وسلف موظفين ومكافأة نهاية خدمة - **دون ادّعاء الامتثال لقواعد GOSI أو نظام العمل السعودي الحالية؛ راجع [docs/payroll.md](docs/payroll.md) للقيود الكاملة قبل أي استخدام فعلي**، **المرحلة 8 (الوحدات المتقدمة والتكاملات)** بشكل كامل وحقيقي وقابل للتشغيل والاختبار: مصروفات تشغيلية مُرحّلة فورًا، أصول ثابتة مع إهلاك شهري بطريقة القسط الثابت، ميزانيات تقديرية للمقارنة فقط، وسقالة تكامل سلّة (Salla) **غير مُفعَّلة إطلاقًا** (تشفير حقيقي للإعدادات واستقبال Webhook للتدقيق فقط، بلا أي استدعاء صادر فعلي لواجهة برمجة تطبيقات سلّة؛ راجع [docs/salla-integration.md](docs/salla-integration.md))، و**المرحلة 9 (الأمان والجودة)** بشكل جزئي وحقيقي وقابل للاختبار: مراجعة أمنية فعلية (إصلاح نقطتي نهاية عامتين بلا تحديد معدل طلبات)، توزيع صلاحيات دقيق وفعلي لكل الأدوار الستة عشر غير الإدارية مع فصل مهام مُختبَر عبر HTTP حقيقي، وتحسينات إمكانية وصول مُختبَرة على المكوّنات المشتركة - **دون ادّعاء اجتياز مراجعة أمنية رسمية من طرف ثالث أو توافق WCAG كامل؛ راجع [docs/security-review.md](docs/security-review.md) و[docs/accessibility.md](docs/accessibility.md)**. بقية المراحل (التوظيف والخدمة الذاتية، التصنيع) **لم تُبنَ بعد** كما هو موضّح في [خطة المراحل](docs/phases.md). لا تتضمن الواجهة أي صفحات أو أزرار وهمية لوحدات لم تُبنَ بعد.

## المكوّنات التقنية

| الطبقة | التقنية |
|---|---|
| الواجهة الأمامية | Next.js 16 (App Router) + React 19 + Tailwind CSS 4 |
| الخادم / API | NestJS 11 (TypeScript) |
| قاعدة البيانات | PostgreSQL 16 + Prisma ORM 6 |
| المصادقة | Argon2id + JWT (وصول قصير الأمد + تحديث بالتدوير Refresh Token Rotation) |
| التحقق من المدخلات | Zod (مشتركة بين الخادم والواجهة) |
| التوثيق | OpenAPI/Swagger على `/api/docs` |
| الحاويات | Docker + docker-compose |

## هيكل المستودع

```
apps/
  api/      خادم NestJS (واجهة برمجة التطبيقات)
  web/      تطبيق Next.js (الواجهة الأمامية)
packages/
  db/       مخطط Prisma، الترحيلات (migrations)، سكربت الزراعة (seed)
  shared/   أنواع ومخططات Zod مشتركة بين الخادم والواجهة
docs/       الوثائق العربية (تثبيت، نشر، دليل المدير، مخططات)
```

## التشغيل السريع (تطوير محلي)

```bash
cp .env.example .env
# عدّل .env: كلمات مرور قاعدة البيانات، أسرار JWT، بريد/كلمة مرور المدير

npm install
docker compose up -d postgres           # أو استخدم PostgreSQL محلي
npm run prisma:migrate
npm run prisma:seed

npm run dev:api     # http://localhost:4000  (التوثيق: /api/docs، الصحة: /api/health)
npm run dev:web     # http://localhost:3000
```

راجع [دليل التثبيت](docs/installation.md) و[دليل النشر](docs/deployment.md) للتفاصيل الكاملة.

## تسجيل الدخول الأولي

يُنشأ حساب المدير تلقائيًا عند تشغيل سكربت الزراعة (seed) من متغيرات البيئة `ADMIN_EMAIL` و`ADMIN_PASSWORD`. إن لم تُحدَّد كلمة مرور، يُولَّد سطر عشوائي قوي ويُطبع مرة واحدة في سجلات التشغيل. يُجبر النظام المدير على تغيير كلمة المرور فور أول تسجيل دخول.
